Recursion & Dynamic Programming

The Core Concepts

Recursion

A function calling itself to solve smaller instances of the same problem. It requires a Base Case (to stop) and a Recursive Step.

Drawback: It often suffers from "Overlapping Subproblems", calculating the exact same thing multiple times.

Dynamic Programming (DP)

An optimization technique that solves overlapping subproblems by saving the answers in memory. DP = Recursion + Memory.

  • Top-Down (Memoization): Keep the recursive structure, but save results to a Hash Map/Array.
  • Bottom-Up (Tabulation): Remove recursion entirely. Use loops to build an array from the base cases upward.
